Hatsune Miku Logic Paint S+ - Mod Hook
=======================================

Installation:
1. Place winmm.dll into your Hatsune Miku Logic Paint S+ game folder (where MikuLogiS+.exe is located).
2. Launch the game through Steam.
3. Press F2 in-game to open the configuration overlay.

Features:
- F2 In-Game Overlay
- Visual Customization: Background themes and board skins
- Visual Customization: Costume head & body gender variants
- Optional Helper Tools: Native click auto-solver & bonus stage unlock (configured via mods/cheats.ini)
